# 📋 Cadastro de Funcionários — Java

Programa em Java que cadastra funcionários com ID, nome e salário. Permite aplicar aumento salarial e exibe a lista atualizada.

## 🔧 Funcionalidades
- Cadastro com ID único  
- Aumento de salário por percentual  
- Exibição da lista final

## 🛠️ Conceitos
- Programação Orientada a Objetos (POO)  
- ArrayList  
- Stream API
